# 模型接入说明

本项目需要**一个多模态（能看图）大模型 API**。没有它，系统只能跑模拟模式——
模拟模式的结果是程序按文件名猜出来的，**不是识别结果**，不能写进报告。

本文只用国内可直连、有免费额度的方案，不需要翻墙。

---

## 一、推荐：智谱 GLM-4V-Flash（永久免费）

`glm-4v-flash` 是智谱官方标注的**永久免费**视觉模型，国内直连，接口兼容 OpenAI 协议。
对本项目这种「每张图一次调用、共 80~200 张」的用量来说完全够用。

### 1. 注册并拿 Key（约 2 分钟）

1. 打开 https://open.bigmodel.cn
2. 用手机号注册 / 登录
3. 进入「API Keys」页面：https://open.bigmodel.cn/usercenter/proj-mgmt/apikeys
4. 新建一个 API Key，复制出来（形如 `xxxxxxxx.xxxxxxxx`）

> 免费模型有并发限制（约 1~2 并发），高峰期可能返回 429。本项目是串行调用，
> 一般不会触发；真遇到时把 `--max-frames` 调小、或隔几分钟重跑即可。

### 2. 配置（两种方式，任选其一）

#### 方式 A：写 `.env` 文件（推荐）

在**项目根目录**新建一个 `.env` 文件，内容四行：

```
SAFETY_LLM_API_KEY=e3c3...你的Key
SAFETY_LLM_BASE_URL=https://open.bigmodel.cn/api/paas/v4
SAFETY_LLM_MODEL=glm-4v-flash
SAFETY_LLM_IMAGE_FORMAT=base64
```

程序启动时会自动读取它（`src/llm.py` 里的 `load_env_file`，纯标准库实现，不需要装
python-dotenv）。

为什么推荐这种方式：

- **不会进 git**：`.env` 和 `.env.*` 已在 `.gitignore` 里排除，Key 不会被推到 GitHub
- **不用重开终端**：改完直接跑，立即生效
- **不会残留在命令行历史里**
- 环境变量优先于 `.env`，临时要覆盖某个值仍可以用 `export`

仓库里已放好一份 `/.env.example`，复制改名即可：

```bash
cp .env.example .env      # 然后把 Key 填进去
```

> 组内每人各自配一份 `.env`，**不要**把 Key 发到群里或用同一个 Key 同时跑
> （免费模型有并发限制，容易互相 429）。

#### 方式 B：设环境变量

**Windows PowerShell**（当前窗口有效）：

```powershell
$env:SAFETY_LLM_API_KEY    = "你的 Key"
$env:SAFETY_LLM_BASE_URL   = "https://open.bigmodel.cn/api/paas/v4"
$env:SAFETY_LLM_MODEL      = "glm-4v-flash"
$env:SAFETY_LLM_IMAGE_FORMAT = "base64"     # 智谱吃裸 base64，不带 data: 前缀
```

**Windows 永久生效**（推荐，避免每次开新窗口都要设）：

```powershell
[Environment]::SetEnvironmentVariable('SAFETY_LLM_API_KEY','你的 Key','User')
[Environment]::SetEnvironmentVariable('SAFETY_LLM_BASE_URL','https://open.bigmodel.cn/api/paas/v4','User')
[Environment]::SetEnvironmentVariable('SAFETY_LLM_MODEL','glm-4v-flash','User')
[Environment]::SetEnvironmentVariable('SAFETY_LLM_IMAGE_FORMAT','base64','User')
```

设完要**重开一个终端**才生效。

### 3. 验证

```bash
python src/main.py status
```

必须看到：

```
模型模式：api
API Key：已配置
```

如果还是 `mock`，说明环境变量没被读到——检查是不是没重开终端。

然后再跑一张真实图片：

```bash
python src/main.py analyze --input data/lab/lab_0001.jpg --scenario chemistry_lab
```

## 二、备选方案

| 平台 | 免费模型 | 额度 | 大陆直连 | 说明 |
| --- | --- | --- | --- | --- |
| 智谱 bigmodel.cn | `glm-4v-flash` | 永久免费 | ✅ | **首选**，接入最简单 |
| 阿里云百炼 | `qwen3-vl-flash`、`qwen-vl-max` | 新用户约 100 万 token / 90 天 | ✅ | 额度大，但会过期 |
| 上海 AI 实验室 | `internvl-latest` | 30 RPM，9000 万 token/月 | ✅ | 额度最宽松 |
| Groq / Google AI Studio / OpenRouter | 多种 | 有限额度 | ❌ 需代理 | 本机实测不通，不建议 |

> 免费政策变动频繁，以上为 2026-10 的情况，用前请到各家控制台确认。

### 换用其他平台时

只需要改三个环境变量，代码不用动：

```powershell
$env:SAFETY_LLM_BASE_URL = "https://dashscope.aliyuncs.com/compatible-mode/v1"
$env:SAFETY_LLM_MODEL    = "qwen-vl-max"
```

## 三、`SAFETY_LLM_IMAGE_FORMAT` 这个变量是干什么的

不同平台对「图片怎么传」的要求不一样：

| 取值 | 发送的内容 | 适用 |
| --- | --- | --- |
| `data_uri`（默认） | `data:image/jpeg;base64,/9j/4AAQ...` | OpenAI、通义千问、多数平台 |
| `base64` | `/9j/4AAQ...`（裸 base64） | 智谱 GLM-4V 等 |

**如果调用报 400 或说「图片格式不支持」**，先试着把这一项在两个值之间切换一次，
大概率就好了。这是接入国内视觉模型最常见的一个坑。

## 四、成本估算

`glm-4v-flash` 免费，所以成本为 0。如果换用收费模型，本项目一次完整实验的量级：

| 场景 | 调用次数 | 说明 |
| --- | --- | --- |
| 单张图片分析 | 1~3 次 | 感知 1 次 + Agent 申请工具后回灌 1~2 次 |
| 80 张样本跑一组 | 约 150~250 次 | 基础版约 80 次，多 Agent 版约 200 次 |
| 三组对比 + 两轮自进化 | 约 600~900 次 | 含两次全量回归测试 |

按 `glm-4v-flash` 免费算不花钱；按收费模型（约 0.01 元/千 token 量级）估计，
**整份实验的钱在个位数到十几元之间**，不会成为负担。

---

## 五、注意事项

- **不要把 Key 写进代码或提交到仓库**。`.gitignore` 已经排除了 `.env`，但最稳的是只用环境变量。
- **答辩现场不要用模拟模式**。报告里写「已接入真实模型」但现场跑出 `mock`，会被直接质疑。
- 模型不是判官。它是辅助分析工具，结论必须人工复核。
- 报告里要如实写清用的是哪个模型、哪个版本、调用次数——这是课题要求的一部分。
